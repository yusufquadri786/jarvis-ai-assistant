# Mausam Saathi — Weather Companion

A beginner-friendly, mobile-responsive weather app focused on a simple daily forecast experience.

## Features in this MVP
- Search for a city anywhere supported by Open-Meteo geocoding.
- Current temperature, feels-like temperature, humidity, wind speed and precipitation.
- Seven-day forecast with daily high/low temperatures and precipitation probability.
- English and Hindi interface.
- Responsive layout for phones and laptops.
- No account, API key, backend server or paid API required for this demo.

## Run it
1. Open `projects/mausam-saathi/index.html` in a modern browser, or use VS Code with the Live Server extension.
2. Keep an internet connection on because weather data is fetched live.
3. Search for a city.

## Data source
Weather and geocoding data are provided by [Open-Meteo](https://open-meteo.com/). Review its current terms and attribution requirements before commercial use.

## Important safety note
This is an informational forecast, not an official emergency alert service. For severe-weather warnings, users should follow their official local meteorological department and emergency authorities.
